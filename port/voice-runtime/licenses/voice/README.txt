BT4 optional native voice uses libdatachannel v0.24.6 (MPL-2.0), Opus 1.6.1 (BSD), OpenSSL 3.6.5 (Apache-2.0), and the dependencies licensed here. No source modifications were made to these libraries. The launcher source kit includes the libdatachannel sources with all submodules and the exact build recipe. Opus/OpenSSL binary package hashes are in SOURCES.json. Voice and this Windows build require 64-bit Windows.
